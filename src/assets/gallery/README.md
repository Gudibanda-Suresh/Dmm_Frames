Drop your photos into the matching category subfolder:

- `portraits/`
- `nature/`
- `travel/`
- `street/`
- `culture/`
- `lifestyle/`

Any filename works (e.g. `IMG_0231.jpg`). Every image in a folder shows up
under that category in the Gallery automatically — no code changes needed.
A category left empty keeps showing placeholder photos until you add real
ones.
