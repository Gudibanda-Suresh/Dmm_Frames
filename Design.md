# Photography Portfolio Website Prompt

Create a modern, premium photography portfolio website using **React, Vite, Tailwind CSS, Skeleton UI, and Framer Motion**.

## Design

* Premium Liquid Glass (Glassmorphism) UI
* Apple-inspired minimal design
* Dark theme with elegant typography
* Smooth animations and micro-interactions
* Clean, modern, and responsive layout

## Website Sections

* Hero
* About Us
* Services
* Gallery
* Reels/Videos
* Contact
* Footer

## About Us

We are photographers from **Dharmavaram, Andhra Pradesh**, proudly known as the **Silk City of Andhra Pradesh**. Our goal is to capture timeless memories, cinematic visuals, and authentic stories inspired by our culture, traditions, landscapes, and everyday life.

## Services

* 🎥 Cinematic Shorts & Reels
* 📸 Portrait & Lifestyle Photography
* 🎨 Visual stories inspired by the Silk City of Dharmavaram
* ⚡ Professional photography and videography using **Canon EOS R50**

## Gallery

Create a beautiful masonry-style gallery with categories such as:

* Portraits
* Nature
* Travel
* Street
* Culture
* Lifestyle

Include smooth hover animations and a lightbox to view images.

## Language Support

The website must support **English** and **Telugu**.

* Add a language switcher in the navigation bar.
* Use **React i18next** for translations.
* Switching languages should update all text instantly without refreshing the page.
* Remember the selected language using Local Storage.
* Default language should be English.

## Responsive Design

The website should be fully responsive and optimized for:

* Mobile
* Tablet
* Laptop
* Desktop

Include a mobile-friendly navigation menu with smooth animations.

## Contact Section

Include:

* Contact Form

## Performance

* SEO-friendly
* Lazy-load images

The final website should feel premium, cinematic, elegant, and modern while showcasing the beauty of **Dharmavaram, the Silk City of Andhra Pradesh**, with a seamless bilingual experience in English and Telugu.
